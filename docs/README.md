# AIRLOCK 효과도(MOE)·시스템 분석 도구 — 문서 허브

C-UAS 요격 체계(AB-U10)의 효과도와 시스템 트레이드오프를 분석하고 요구사항을 도출하는 도구입니다.

## 실행

- 원클릭: 저장소 루트의 `run.cmd`
- 터미널: `pnpm install` 후 `pnpm start`
- 주소: <http://localhost:5174/>
- 분석 진입: 운용 화면의 `효과도 분석 ▸` 또는 `A`
- 검증: `pnpm test` · `pnpm exec tsc -b` · `pnpm build`

## 현재 시간선

```text
레이더 탐지 → C2 발사 결심 → AB-U10 발사 → 탑재 EO 인식/식별 → 요격
```

- 발사거리는 좌측 `발사 개시 거리 (교리)`가 결정합니다.
- P_detect는 진입거리부터 필요 탐지거리까지의 `적시 누적 탐지확률`이며, keep-out 전 전체 누적은 참고값으로 분리합니다.
- EO 완료거리는 발사 후 `AB-U10 카메라↔표적 상대 LOS`입니다.
- EO 설계 탭은 목표 거리·픽셀에서 HFOV/IFOV/초점거리를 역산하지만 발사거리를 덮어쓰지 않습니다.
- 0.35 m·1920 px·500 m·20 px는 HFOV 약 3.85°, 2 m 표적이면 약 22.00°입니다.

## 기능

- 해석식/몬테카를로 교전 효과도와 병목 진단
- EO/IR 광학 역설계 및 발사 후 상대거리 시간선
- 커버리지·1D/2D 트레이드·스펙 역산·A/B 비교
- CSV/JSON/Markdown 리포트와 파라미터별 수식·가정·출처

모든 기본값은 편집 가능한 가정·요구값이며 확정 성능치가 아닙니다. SME 검증이 필요합니다.
